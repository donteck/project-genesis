# Project Genesis Foundation Registry

Foundations are timeless truths.

Unlike Discoveries, which record moments when understanding fundamentally changed, Foundations are intended to remain stable across generations. They preserve the enduring principles that should guide builders regardless of product, technology, milestone, or era.

Each Foundation contains:

- Number
- Title
- Date
- Summary
- Related Discoveries
- Related Blueprints
- Related Constitutions

## Permanence

Foundations should be treated as stable, intergenerational guidance. They may be clarified as Project Genesis matures, but their essential truths should not be changed merely to follow technology, fashion, or short-term priorities.
