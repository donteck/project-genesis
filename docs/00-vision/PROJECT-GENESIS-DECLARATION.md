# The Project Genesis Declaration

We believe knowledge should never be trapped.

We believe learning should be accessible.

We believe artificial intelligence should amplify educators, not replace them.

We believe every person has knowledge worth sharing.

We believe technology should organize knowledge so it can reach generations to come.

We believe education changes lives.

We are building the platform that helps make that possible.

## Platform Promise

> Create once. Teach forever.

## Team Motto

> Vision inspires. Architecture delivers.

## Engineering Oath

We do not build software simply because we can.

We build software that helps people learn, grow, and create opportunities.

Every feature must serve that purpose.

Quality matters. Integrity matters. People matter.
