# Project Genesis Manifesto

The Manifesto is the enduring philosophical declaration of Project Genesis. It expresses beliefs, commitments, and promises intended to guide every generation of builders and changes only under extraordinary circumstances.

Within the recommended governing hierarchy, the Manifesto follows the Vision and precedes [The Genesis Covenant](../foundation/THE_GENESIS_COVENANT.md), which in turn precedes [The Genesis Declaration](../foundation/THE_GENESIS_DECLARATION.md). The [Project Genesis Foundation](../foundation/README.md) explains the complete hierarchy and preserves the highest-level governing-document relationships.

The canonical long-form Manifesto remains reserved for its formally approved publication. Related manifesto-era material is preserved in [Volume 03 — The Manifesto](../library/Volume-03-The-Manifesto/README.md) and the [Genesis Evolution Manifesto](../GENESIS_EVOLUTION_MANIFESTO.md).
