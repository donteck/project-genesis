# ADR-002: Platform Name and Category

- **Status:** Accepted
- **Date:** 2026-07-30
- **Decision owner:** Emmanuel Tuffet

## Decision

The product's working official name is **Uwebbz LearningOS**.

Its category is **AI Education Operating System**.

## Rationale

The platform is broader than a traditional LMS. It coordinates roadmaps, course generation, content storage, publishing, student learning, assessments, certificates, analytics, and multi-academy operations.

## Consequences

- Product language should emphasize an operating system and education engine rather than only an LMS.
- The architecture must support multiple academies from one reusable core.
- Individual tools should behave as connected modules within one platform.
