# ADR-001: Product Mission

- **Status:** Accepted
- **Date:** 2026-07-30
- **Decision owner:** Emmanuel Tuffet

## Context

Project Genesis needs a permanent mission that guides product, architecture, and business decisions.

## Decision

Uwebbz LearningOS will transform knowledge into opportunity through AI-powered education.

The platform promise is:

> Create once. Teach forever.

## Decision Test

Every major feature should answer:

> Does this help someone learn better?

## Consequences

- Learning outcomes take priority over novelty.
- AI supports educators rather than removing human authority.
- Generated content must be reusable across multiple formats.
- Features unrelated to the mission should be delayed, redesigned, or rejected.
