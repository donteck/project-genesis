## Quality Controls

Before a milestone is marked complete in the repository:

- The milestone number and title must be unique.
- The file must use the approved naming convention.
- All required architecture sections must be present.
- Internal links must resolve.
- The previous and next milestone references must be correct.
- Completion claims must match the actual repository files.
- Implementation work must remain separated from blueprint documentation.
- No major decision should exist only in chat.
